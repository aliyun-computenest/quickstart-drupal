概述

Drupal 是使用 PHP 编写的开源内容管理框架（CMF），由内容管理系统（CMS）与 PHP 开发框架共同构成，可用于构建从个人博客到大型社区的各类动态网站。更多信息，请参见 Drupal 官网。

本文介绍如何使用计算巢部署 Drupal 社区版服务实例。部署完成后，环境（Ubuntu 24.04 + Apache2 + PHP 8.3 + RDS MySQL 8.0）与 Drupal 11 站点均已自动装好，直接登录后台即可开始使用，无需再执行安装向导。

说明：当您的账号是 RAM 账号时，才需要添加此权限。

部署流程

  1. 访问计算巢 Drupal 社区版部署链接，按提示填写部署参数。

  1. 参数填写完成后可以看到对应询价明细，确认参数后点击下一步：确认订单。

  1. 确认订单完成后同意服务协议并点击立即创建进入部署阶段。

  1. 部署成功后进入服务实例详情页，在输出中可以看到以下地址与账号：
输出 说明
DrupalEndpoint 站点首页地址，形如 http://<公网IP>
AdminUrl 后台登录地址，形如 http://<公网IP>/user/login
AdminUsername 后台管理员账号，固定为 drupal_admin
DBConnectString RDS 内网连接地址

  1. 打开 DrupalEndpoint，站点已经初始化完成，可以直接访问；无需再执行安装向导。

  2. 打开 AdminUrl，使用账号 drupal_admin 与部署时填写的 Drupal 管理员密码登录后台，即可开始创建内容。

默认安全配置

镜像与模板已完成以下加固，无需额外操作：

  • vendor/、composer.json、composer.lock、README.md 等非 Web 资源禁止访问；
  • core/install.php 与 update.php 禁止通过浏览器访问（升级请在服务器上用命令行执行）；
  • sites/default/settings.php 权限 440，Web 进程不可写、不可通过浏览器读取；
  • 文件目录 sites/default/files 内禁止执行 PHP 脚本，防止上传后门；
  • PHP 配置 expose_php = Off，响应头不暴露 PHP 版本。

常见问题

部署完成后访问 DrupalEndpoint 打不开怎么办？

部署完成后约 1~2 分钟内初始化脚本仍在执行，请稍等后刷新；若长时间无法访问，可在服务实例详情页查看部署日志确认初始化是否报错。

为什么访问 /core/install.php 或 /update.php 返回 403？

这是默认加固策略，避免站点被重复安装或被未授权触发升级。需要执行数据库更新时，请登录 ECS 后在 /opt/drupal 下使用 drush 或 php core/scripts/db-tools.php 等命令行方式操作。

忘记管理员密码怎么办？

可登录 ECS 实例，在 /opt/drupal 目录下执行 drush user:password drupal_admin <新密码>，或重新部署一个新的服务实例。

能否绑定自己的域名并开启 HTTPS？

可以。站点默认使用 http://<公网IP> 访问，如需绑定域名与证书，可在 ECS 上自行配置 Apache 虚拟主机，或在前端接入负载均衡 / CDN 统一处理证书。
